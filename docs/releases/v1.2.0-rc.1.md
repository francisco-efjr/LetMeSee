# LetMeSee 1.2.0-rc.1 · avaliação

Aplicativo compilado para download. A preparação vem antes do espelhamento; depois do checklist, a tela principal tem somente **Ambiente** e **Começar a espelhar**.

## Windows

Baixe **LetMeSee-1.2.0-windows-x64-portable.zip**. Requer Windows 10/11 x64, .NET Framework 4.8 e Windows PowerShell 5.1. Não é necessário instalar compilador.

1. Compare o SHA-256 do ZIP com **SHA256SUMS-windows.txt**.
2. Para os scripts opcionais não herdarem o bloqueio do download, abra **Propriedades** do ZIP e marque **Desbloquear**, se disponível, antes de extrair. Não mude a política global de execução.
3. Extraia em uma pasta do seu usuário e abra **LetMeSee.exe**.
4. Escolha o ambiente e conclua o checklist. A preparação dos componentes acontece somente quando você solicitar.

O ZIP contém o aplicativo, scripts, configurações e instruções. UxPlay, GStreamer, Bonjour, scrcpy e adb não estão incluídos. O instalador completo com runtime legado continua retido até concluir o inventário de distribuição dos componentes.

## O que mudou

- Checklist contextual para Android/iPhone/iPad, Windows/macOS, USB/rede e instruções guiadas ou técnicas.
- Diagnósticos automáticos separados das confirmações sobre aparelho, rede e privacidade.
- Android somente visualização, clipboard desativado, aparelho explícito e servidor ADB próprio em loopback.
- AirPlay no Windows e orientação de AirPlay/QuickTime do sistema no Mac.
- Nova conferência antes de iniciar; mudança de aparelho/contexto, suspensão, interrupção e expiração exigem preparação renovada.
- Paleta Pulse, textura de papel local e estados explicados por texto.
- Correções dos testes Windows e da compilação concorrente Swift detectadas nos builds do GitHub.

## macOS

O ZIP macOS identifica a arquitetura no nome e contém o app nativo, sem as ferramentas Android. Confira **SHA256SUMS-macos.txt** antes de extrair. Requer macOS 13+ e hardware compatível com o método escolhido. As rotas Apple são orientações: o LetMeSee não detecta nem encerra a sessão do sistema.

## Limites desta pré-release

Os aplicativos não têm assinatura de distribuição/notarização. Não altere proteções do sistema para tentar resolver um bloqueio. Os testes de CI verificam lógica, processos fictícios, scripts e compilação; não comprovam transmissão com um celular real.

Testes físicos com Android/iPhone, áudio, UAC/firewall/Bonjour, upgrade/desinstalação e acessibilidade ainda precisam ser concluídos. Esta versão é para avaliação, não uma declaração de estabilidade. Não há telemetria, conta ou gravação automática implementadas pelo aplicativo.
